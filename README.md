# FIFA vs UEFA Tie-Breaking Rules: Which Creates More Group-Stage Suspense?

**Alessandro Di Mattia and Alex Krumer**

This repository contains the data and code for a paper comparing the group-level suspense generated by the two main tie-breaking systems in international football: FIFA's goal-difference criterion and UEFA's head-to-head criterion.

---

## Main Finding

**FIFA's goal-difference rule generates significantly more group-level suspense in the World Cup than UEFA's head-to-head rule.**

A goal scored on the last matchday of the group stage under FIFA rules is associated with a **4.2 percentage point higher probability** of occurring in a suspenseful state ($p < 0.01$). This advantage is robust to controlling for competitive balance (Elo standard deviation) and holds uniformly across groups of varying team quality.

The European Championship serves as a placebo: applying the same analysis to Euro data produces no statistically significant difference between the two rules ($p = 0.389$), suggesting the effect is specific to the World Cup's institutional context rather than a mechanical property of the rules themselves.

---

## What is Suspense?

We introduce a binary group-level suspense indicator:

> *A suspenseful moment occurs when a single additional goal in any ongoing group match would change which teams qualify for the knockout stage.*

This is a new concept in the sports economics literature. Unlike existing match-level measures of suspense, surprise, and shock — which capture belief shifts about a single match outcome — our indicator captures how goal events reshape the broader qualification picture across the group.

## Data

- **FIFA World Cup**: editions 1986–2022 (455 matchday-3 goals; 74 groups across 10 editions)
- **UEFA European Championship**: editions 1984–2024 (270 matchday-3 goals; 44 groups across 11 editions)

Data were scraped from Wikipedia and cross-checked against official FIFA and UEFA sources. Elo ratings are retrieved from [international-football.net](https://www.international-football.net/) and are embedded directly in the processed datasets.

```
data/in/           Elo ratings
data/out/wiki/men/ Processed matchday-3 datasets (goals and minute-by-minute)
  fifa/eu/         European Championship under FIFA rules
  uefa/eu/         European Championship under UEFA rules
  fifa/wc/         World Cup under FIFA rules
  uefa/wc/         World Cup under UEFA rules
```

## Empirical Strategy

The regression stacks FIFA and UEFA observations for each group so that identification comes from within-group variation across rule regimes. We estimate a **goal-level linear probability model (LPM)**:

$$\textit{suspense}_{gmk} = \alpha + \beta\,\textit{FIFA}_{gm} + \gamma\,t_k + \delta\,t_k^2 + \lambda\,\textit{EloDiff}_{gmk} + \mu_y + \varepsilon_{gmk}$$

where $k$ indexes goals within match $m$ of group $g$, $\textit{FIFA}_{gm}$ is a dummy equal to 1 for FIFA-rule observations, $t_k$ is the goal minute, $\textit{EloDiff}_{gmk}$ is the absolute Elo rating difference between the two teams, and $\mu_y$ are year fixed effects. Standard errors are clustered at the group (year $\times$ stage) level.

A second specification adds group-level Elo standard deviation and its interaction with the rule dummy to test whether the FIFA advantage varies with competitive balance — it does not ($p > 0.10$).

## Key Results

| | European Championship | World Cup |
|---|---|---|
| Suspense diff (UEFA − FIFA) | −0.015 | **−0.040** |
| t-test p-value | 0.389 | **0.008** |
| Wilcoxon p-value | 0.438 | **0.010** |
| FIFA rule coef (Spec 1) | 0.009 (n.s.) | **0.042\*\*\*** |
| N groups | 44 | 74 |

FIFA rules generate more suspense in the World Cup across all tests. The effect is both statistically significant and stable over the 90 minutes of play: unlike under UEFA rules — where uncertainty tends to concentrate in the closing stages — FIFA rules keep the qualification race open throughout the match.
